# ZoomPaper 完整功能与操作指南

ZoomPaper 是面向中文用户的论文管理与 AI 阅读工具。左侧导航依次进入论文库、阅读时间线、论文搜索、知识库问答、帮助和设置。本文档是软件内“问 AI”的唯一产品知识来源；回答操作问题时，应给出简短、具体、可执行的步骤。

## 一、论文库

### 1. 智能分类的关系

- **全部论文**：所有未删除论文。收藏、文件夹和未分类都是全部论文的子集。
- **收藏**：所有已加星标的论文。收藏不会把论文移出全部论文或原文件夹。
- **未分类**：没有加入任何文件夹的论文。
- **回收站**：已删除论文。可恢复或永久删除；清空回收站会永久删除其中全部论文。
- **文件夹**：用户自定义分类。一篇论文可以同时属于多个文件夹，文件夹也可以有子文件夹。
- 侧栏分类和文件夹右侧的数字始终表示当前论文数量，包括 `0`。
- 当所选分类没有论文时，论文列表区域保持留白，不显示空状态图标或说明文字。

### 2. 导入论文

1. 点击论文库右上角的上传图标。
2. 选择一个或多个 PDF。
3. PDF 保存后即可打开原文。正文解析在后台排队，索引、中文标题摘要和 DOI 补全分别执行，不阻塞继续导入。

出版信息补全：解析后自动从网页 DOI 或 PDF 首页 DOI 查询 Crossref，未收录时尝试 DataCite。核对标题后补全缺失的会议／期刊、年份和作者；无需配置账号或 API Key，不消耗模型 Token。已有具体会议信息和自定义标题保留。旧论文点击打开概览或阅读时也会尝试补全。无 DOI 或查询失败时仍可正常使用，软件不会根据参考文献猜测发表会议。查询仅发送 DOI，结果缓存在本机。

### 3. 打开论文

1. 双击论文行或卡片。
2. 也可以右键论文，选择打开。
3. 阅读工作区会显示 PDF、AI 翻译、博客、费曼学习和测验等入口。

### 4. 收藏论文

1. 选中一篇论文。
2. 点击右侧论文信息栏中的星标图标。
3. 收藏后论文仍在全部论文和原文件夹中，同时出现在左侧“收藏”。
4. 再次点击星标可取消收藏。

### 5. 添加到文件夹

单篇论文：

1. 右键论文。
2. 点击文件夹图标或“添加到文件夹”。
3. 勾选一个或多个目标文件夹。
4. 点击“完成”后才应用更改。

多篇论文：

1. 长按任意论文进入多选，再选择其他论文。
2. 点击批量工具栏中的文件夹图标。
3. 弹窗中的勾选状态表示：全部已在该文件夹、部分在该文件夹或全部不在。
4. 勾选或取消目标文件夹，点击“完成”后统一应用。
5. 关闭或取消弹窗不会修改文件夹归属。

### 6. 快速多选

1. 长按任意论文，保持按住并直接向上或向下滑动，可连续选择经过的论文。
2. 进入多选后，点击复选框可继续选择或取消论文。
3. 也可以按住一个复选框拖动，连续选择或取消。
4. 完成批量操作后自动退出多选。
5. 点击论文列表空白处或按 `Esc` 也可退出多选。
6. `Command/Ctrl + A` 可全选当前列表。

### 7. 阅读状态

论文有未读、在读和已读三种状态。

1. 右键论文，或进入多选后点击状态图标。
2. 选择未读、在读或已读。
3. 论文库顶部筛选器可以只看某一种状态。
4. 打开和阅读论文时，状态与最后阅读时间会随使用情况更新。

### 8. 阅读计划

1. 右键论文，打开“加入阅读计划”。
2. 选择现有计划或新建计划。
3. 选择今天、明天或自定义日期。
4. 论文会出现在时间线页面对应计划和日期中。

### 9. 重命名论文

1. 右键论文。
2. 选择重命名。
3. 输入新标题并确认。此操作只修改论文库中的显示标题，不改原 PDF 文件内容。

### 10. 导出笔记

1. 右键单篇论文，或多选论文。
2. 点击下载图标或导出笔记。
3. 选择保存位置。导出内容包括已有高亮和批注。

### 11. 删除、恢复与清空回收站

1. 右键论文或多选论文，点击删除。
2. 论文先进入回收站，不会立刻永久丢失。
3. 打开左侧回收站，可恢复单篇论文或永久删除。
4. 点击回收站顶部的清空按钮，可永久删除回收站全部内容。

### 12. 搜索、筛选、排序与布局

- 顶部搜索框可匹配标题、作者、摘要、期刊或会议。
- 状态筛选器可选全部、未读、在读、已读或收藏。
- 排序可选添加时间、最近阅读或标题。
- 点击列表或网格图标切换布局。
- 列表行和卡片上的来源图标来自论文网页；无法取得时使用通用文档图标。
- 列表视图右键论文与右侧“更多”按钮打开相同菜单。
- 单击列表论文会打开右侧预览；拖动预览左侧分隔线可调整列表与预览的宽度比例。
- 解析完成后会同步生成中文标题和摘要；在右侧预览点击“原文 / 中文”切换。旧论文首次切换中文时会自动补译并缓存。

### 13. 管理文件夹

1. 点击侧栏底部的加号新建文件夹；也可右键“全部论文”或“收藏”新建。
2. 输入文件夹名称，选择颜色，需要时添加标签。
3. 右键已有文件夹可新建子文件夹、重命名、修改颜色与标签或删除。
4. 论文可以拖到文件夹；拖到未分类会移除其文件夹归属。

### 14. 重新解析

1. 在论文库右键论文。
2. 点击解析或重新解析。
3. 等待解析完成。适用于正文、摘要、作者、期刊会议等信息不完整的论文。

## 二、论文阅读

### 1. PDF 阅读与进度

1. 从论文库打开论文。
2. 使用滚轮阅读 PDF。
3. 阅读时长、最后阅读时间和位置会自动记录。
4. 顶部标签允许同时打开多篇论文并来回切换，固定“论文库”标签返回列表。
5. 切换时间线、设置等板块后，回到论文库继续原来的论文。
6. 多选工具栏的打开图标可批量添加论文标签；拖动标签调整顺序，中键或 × 关闭。
7. 标签优先缩小宽度；数量超过可见空间时，右上角列表可搜索并切换全部论文。旁边 × 一键关闭全部，8 秒内点击提示中的“撤销”恢复整组。
8. Ctrl/Cmd+W 关闭当前论文，Ctrl/Cmd+Shift+T 恢复刚关闭的标签，Ctrl/Cmd+Tab 切换。
9. 打开的标签会在重新启动后恢复；只为当前显示的论文累计阅读时长。

### 2. 目录、跳页与缩放

- 点击目录图标打开章节目录，再点击章节定位。
- 使用页码控件跳到指定页。
- 使用缩放按钮放大、缩小或适合页面。

### 3. 高亮

1. 在 PDF、译文或博客中选中文字。
2. 点击浮动工具栏中的高亮图标。
3. 在笔记列表查看高亮；点击记录可回到原位置。

### 4. 批注

1. 选中文字。
2. 点击批注图标。
3. 输入笔记并保存。
4. 在笔记列表中定位、查看或删除批注。

### 5. 划词翻译

1. 在 PDF、译文或博客中选中单词、术语或短句。
2. 点击翻译图标。
3. 结果显示在选区旁。单词和术语只返回精炼中文释义，短句直接返回译文。

### 6. 针对选文提问

1. 选中文字。
2. 点击提问图标。
3. 选中内容会作为上下文送入当前论文的 AI 助手。
4. 在右侧继续输入问题并发送。

### 7. 论文来源与 GitHub 项目

1. 打开论文阅读页。
2. 点击右上角的外部链接打开论文来源网页。
3. 如果解析到关联 GitHub 仓库，右上角会出现 GitHub 直达按钮；点击后在浏览器中打开项目。

## 三、AI 助手

### 1. 单篇论文问答

1. 打开论文右侧 AI 助手。
2. 输入问题并发送。
3. 回答以当前论文正文为主要依据。
4. 点击回答中的论文引用可跳回原文位置。

### 2. 快速模式

1. 点击输入框下方的模式按钮。
2. 选择快速。
3. 适合术语解释、直接定位、简短概括等问题。

### 3. 深度模式

1. 点击模式按钮并选择深度。
2. 输入需要多步检索或综合分析的问题。
3. 可展开查看检索和工具调用过程。

### 4. 联网检索

1. 打开 AI 输入框下方的联网开关。
2. 发送需要外部资料的问题。
3. 回答会区分论文引用和网页来源。

### 5. 会话历史与新会话

1. 点击 AI 面板右上角的历史图标。
2. 选择历史会话继续。
3. 点击加号开始新会话。
4. 论文切换后，会话和正在生成的任务按论文保存；返回原论文可继续查看。

### 6. 停止生成

1. 回答生成期间点击停止图标。
2. 已生成内容保留，后续可继续提问。

### 7. 知识库问答

1. 点击左侧知识库问答图标。
2. 输入需要跨论文比较或归纳的问题。
3. AI 会在论文库中检索相关内容。
4. 点击回答引用可打开对应论文和原文位置。
5. 右上角历史图标用于恢复会话，加号用于新建会话。

## 四、AI 翻译与学习

### 1. AI 全文翻译

1. 打开论文并切换到“AI 翻译”。
2. 点击开始翻译。
3. 翻译按段生成并保存；完成后可切换纯中文或中英对照。
4. 译文同样支持高亮、批注和划词操作。

### 2. AI 博客

1. 打开论文并切换到博客。
2. 点击生成博客。
3. AI 会生成易读正文和深度分析，并尽量保留论文图表。
4. 生成期间可以切换到其他论文；返回后继续查看进度和结果。
5. 已有博客可重新生成。

### 3. 费曼学习

1. 打开论文并进入费曼学习。
2. 让 AI 根据论文生成核心概念计划。
3. 检查并确认计划。
4. 每个概念使用独立会话：用户充当老师，把概念讲给 AI 学生。
5. 回答 AI 的追问，再进行概念测验。
6. 通过后进入下一个概念；完成后查看复盘和薄弱点。

### 4. 论文测验

1. 打开论文并切换到测验。
2. 点击新建测验。
3. AI 根据论文内容出题。
4. 完成作答并提交，查看评分、答案和解析。

## 五、论文搜索

### 1. 关键词搜索

1. 点击左侧搜索图标。
2. 选择关键词搜索。
3. 选择论文范围，输入关键词并按回车。
4. 点击结果可回到论文原文。

### 2. 语义搜索

1. 在搜索页面选择语义搜索。
2. 输入一个研究概念或自然语言问题。
3. 系统按含义查找相关段落，而不要求文字完全相同。
4. 点击结果打开对应论文位置。

## 六、阅读时间线与计划

### 1. 阅读时间线

1. 点击左侧日历图标。
2. 热力图显示每天的阅读活动，颜色深浅表示活跃程度。
3. 点击日期查看当天阅读记录和完成情况。

### 2. 建立阅读计划

1. 在时间线页面点击“新建计划”，选择每日目标或论文清单。
2. 从论文右键菜单把论文加入计划。
3. 设置计划日期。
4. 在时间线中查看待读论文和完成进度。

## 七、浏览器扩展

### 1. 安装或更新

1. 解压 ZoomPaper Connector 扩展压缩包。
2. 打开 Chrome 或 Edge 的扩展管理页。
3. 开启开发者模式。
4. 点击“加载已解压的扩展程序”，选择扩展目录。
5. Connector `v0.2.8` 起使用固定扩展 ID；更新时解压新版并点击重新加载即可覆盖升级。更早版本需要先移除一次旧扩展。
6. 升级到 `v0.2.9` 时确认一次下载权限；它用于通过浏览器当前的验证会话导入 OpenReview PDF。

### 2. 从论文网页收集

1. 打开受支持的论文详情页，例如 ACL Anthology、arXiv、OpenReview、IEEE、ACM、Springer、ScienceDirect、PMLR、NeurIPS、CVF、USENIX 或通用 DOI 论文页。
2. 点击扩展按钮，或右键页面选择加入 ZoomPaper。
3. 扩展提取标题、作者、来源页、PDF 地址和网站图标，并打开 ZoomPaper 完成导入。
4. App 保存 PDF 后自动加入后台解析队列；网页存在 GitHub 项目线索时，应用会提供项目直达入口。
5. 若网站要求登录或验证，先在浏览器完成；下载失败时可在恢复页选择其他全文、粘贴 PDF 地址或打开原网页重试。
6. 扩展收到 App 的保存回执后显示“已加入论文库”；解析进度在阅读小伙伴中查看。未确认时可重新发送，同一请求不会重复导入。

## 八、设置

### 1. 配置 AI 服务

1. 打开设置。
2. 选择 OpenAI、Anthropic、Gemini、DeepSeek 或兼容接口。
3. 填写 API 地址、密钥和模型；模型框提供常用建议，也可以直接输入服务商支持的任意模型名称。
4. 保存并测试连接。

AI 配置用于论文问答、知识库问答、全文翻译、划词翻译、博客、费曼学习、测验和帮助问答。

### 2. 配置 MinerU

1. 打开设置 → 导入与解析 → PDF 解析。
2. 填写 MinerU 所需信息。
3. 保存后回到论文库解析论文。

### 3. 展示与阅读偏好

- 设置 → 常规：选择统一标题语言，或分别设置论文库、论文标签、概览和阅读历史；概览摘要也支持英文、中文、中英双语。
- 中文译文缺失时选择“全部翻译”或“保留英文”。设置中的“全部”指非回收站论文的缺失标题与摘要；概览中的“全部”只指当前论文。保留英文不发起 AI 请求，已有中文照常显示。
- 启动时是否恢复论文标签，可在常规中切换。
- 设置 → 论文阅读：控制打开后标记在读、读到末页自动标记已读，以及右侧 AI 助手默认开启。
- 设置 → 阅读伙伴：切换伙伴、角色动画（丰富／普通）、阅读气泡、任务气泡。任务通过伙伴展示，无独立通知配置。

### 4. 自动处理与浏览器扩展

- 设置 → 导入与解析：控制自动解析、补全 DOI/会议、翻译标题摘要和全文；同时解析论文数直接输入正整数，调整后不会中止已运行的论文。
- 自动全文翻译默认关闭，开启后新解析完成的论文才会加入后台翻译；切换页面不打断任务。
- 浏览器扩展 → 加载扩展：定位固定扩展目录，并显示加载步骤。在 Chrome/Edge 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”并选中此目录。浏览器要求用户确认，应用不能静默安装。
- 更新后使用同一目录，在扩展管理页点击重新加载，无需重复新增扩展。

### 5. 数据与文件

- 设置 → 数据与存储：点击存储位置旁的“选择文件夹”，选好后点“确定”再确认迁移；导出包含论文、译文、博客、会话、标注及界面偏好的备份；备份不包含 API 密钥。
- 从备份恢复直接选择备份文件夹；格式或文件不完整会提示。通过校验后，完全退出并重新打开应用时生效；恢复前自动备份当前论文库，保留当前 API 配置。
- 迁移存储位置会复制论文与生成内容、更新数据库路径，并保留旧目录。进行备份、恢复或迁移前，先等待后台任务完成。
- 维护可重建向量索引、清理 DOI 查询缓存、清空回收站。清理缓存保留论文与译文；清空回收站会永久删除文件。

## 九、帮助

### 1. 浏览功能手册

1. 点击左侧帮助图标。
2. 先选择页面分类，再点击具体功能。
3. 右侧会显示该功能使用的图标、用途和逐步操作。

### 2. 问 AI

1. 在帮助页面底部输入“有没有某个功能”或“具体怎么操作”。
2. 发送问题。
3. AI 只根据本功能指南回答；若指南没有记载，应明确说明无法确认，不应编造按钮或操作。

## 十、常用快捷操作

- 将鼠标停在只有图标的按钮上，可查看用途提示。
- 右键论文可打开与“更多”按钮相同的操作菜单。
- 长按论文进入多选。
- 点击论文列表空白处或按 `Esc` 退出多选。
- `Command/Ctrl + A` 全选当前论文列表。
- `/` 或 `Command/Ctrl + F` 聚焦论文库搜索。
- 在输入框中按 `Enter` 发送；中文输入法正在组词时不会误发送。


## 阅读小伙伴与后台任务

- **状态气泡**：阅读、导入、解析、全文翻译或博客生成时显示；没有阅读或任务时只显示角色。关闭提示不取消任务。
- **任务列表**：任务气泡默认最多两行；点击气泡展开全文、页数进度、失败原因和操作。点击论文可打开原文。
- **取消与重试**：导入、解析等服务端任务行的停止按钮取消该阶段；失败或停止后点击重试。取消本地索引时要等待当前计算结束，结果不会写入。
- **全文翻译与博客**：切换页面或关闭论文标签后继续生成，气泡显示状态；失败后可重试。退出应用会停止未完成请求，重启后会提示重试；全文翻译利用已保存的分块继续，博客重新生成。
- **多篇导入**：可连续从浏览器导入，或一次选择多个本地 PDF。最多同时解析两篇；索引、元数据翻译和 DOI 查询各自串行，避免占满本机和 API。
- **恢复**：任务写入本机数据库。重启后恢复排队，并使用已保存的 MinerU 批次继续查询。云端解析可能排队；超过 30 分钟会提示超时并允许重试。
- **原文与 AI**：PDF 保存后即可阅读。正文解析完成后可翻译、提问；索引和元数据翻译分别完成。某个后续步骤失败不会撤销已解析的正文。
- **移动与收起**：默认位于右上角的独立透明悬浮窗。按住角色拖动超过 6 像素后移动窗口；透明区域允许点击桌面。
- **快捷操作**：鼠标移到角色或气泡上，显示带玻璃背景的“导入论文”和“继续阅读”；移开后隐藏，不改变气泡位置。
- **显示开关**：角色右上角的 × 隐藏伙伴；在设置中的“阅读伙伴”开关重新打开。隐藏不影响后台任务。
- **角色动作**：待机眨眼、阅读翻页、处理任务轻扇翅、完成点头、失败歪头、空闲休息；遵循系统减少动态效果设置。
- **Connector 升级**：`v0.4.0` 需要允许访问 `127.0.0.1:37541`，只用于核对本次导入是否已保存。无需配置端口、账号或密钥。保持已加载的扩展目录不变，覆盖文件后点击重新加载。

论文全文翻译由应用级任务管理：切换论文或页面后继续翻译，返回时恢复进度；每完成一块保存译文，同一篇论文不会重复启动翻译。自动补译同样在后台完成并保存。此机制支持切换页面，完整退出应用仍会停止未完成的请求。


## 主题配色

设置 → 常规 → 主题配色。可选默认、黑白、红、蓝、紫、黄、深色，或设置自定义主色。切换立即生效，重启后保留；完整备份包含主题偏好。

测验最多支持 30 道选择题和 5 道主观题，默认仍为 5 道选择题和 0 道主观题。


### 5. 自定义主题（JSON 高级主题）

高级主题可以覆盖配色方案的任意颜色变量，适合做整套界面配色。

1. 在设置 → 常规 → 高级主题中点击「主题目录」。
2. 在目录中新建一个 `.json` 文件，内容如下（只需写要覆盖的变量）：

```json
{
  "name": "暖纸",
  "vars": {
    "background": "#fdf6ec",
    "foreground": "#3a3226",
    "card": "#fffdf8",
    "primary": "#b45309",
    "accent": "#f5ead6",
    "accent-foreground": "#7c3d06",
    "border": "#e8ddc9",
    "zp-primary": "#3a3226",
    "zp-secondary": "#6b5f4c",
    "zp-trans-zh": "#92600f"
  },
  "dark": {
    "background": "#1a1512"
  }
}
```

3. 回到设置点「刷新」，在「高级主题」下拉中选择该主题，即时生效。
4. 选择「无」即可恢复纯配色方案。

- `vars` 总是生效；`dark` 段仅在配色方案为「深色」时生效，可省略。
- 变量名对应界面元素：`background`/`foreground` 页面背景与文字，`card` 卡片面，`primary` 主按钮与强调，`accent` 柔和强调底，`border` 边框，`muted` 弱化背景，`sidebar` 侧栏，`zp-primary`~`zp-quaternary` 四级正文文字，`zp-surface` 系列表面，`zp-trans-zh` 中英对照的中文段颜色。
- 变量值支持 hex、oklch、rgba 等任意 CSS 颜色；变量名只能是小写字母、数字和连字符。
