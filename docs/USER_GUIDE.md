# ZoomPaper 完整功能与操作指南

ZoomPaper 是面向中文用户的论文管理与 AI 阅读工具。左侧导航依次进入论文库、阅读时间线、论文搜索、知识库问答、帮助和设置。本文档是软件内“问 AI”的唯一产品知识来源；回答操作问题时，应给出简短、具体、可执行的步骤。

## 一、论文库

### 1. 智能分类的关系

- **全部论文**：所有未删除论文。收藏、文件夹和未分类都是全部论文的子集。
- **收藏**：所有已加星标的论文。收藏不会把论文移出全部论文或原文件夹。
- **未分类**：没有加入任何文件夹的论文。
- **回收站**：已删除论文。可恢复或永久删除；清空回收站会永久删除其中全部论文。
- **文件夹**：用户自定义分类。一篇论文可以同时属于多个文件夹，文件夹也可以有子文件夹。
- 侧栏分类和文件夹右侧的数字始终表示当前论文数量，包括 `0`。
- 当所选分类没有论文时，论文列表区域保持留白，不显示空状态图标或说明文字。

### 2. 导入论文

1. 点击论文库右上角的上传图标。
2. 选择一个或多个 PDF。
3. 导入后等待解析完成。解析会提取标题、作者、摘要、期刊或会议、正文和检索索引。

### 3. 打开论文

1. 双击论文行或卡片。
2. 也可以右键论文，选择打开。
3. 阅读工作区会显示 PDF、AI 翻译、博客、费曼学习和测验等入口。

### 4. 收藏论文

1. 选中一篇论文。
2. 点击右侧论文信息栏中的星标图标。
3. 收藏后论文仍在全部论文和原文件夹中，同时出现在左侧“收藏”。
4. 再次点击星标可取消收藏。

### 5. 添加到文件夹

单篇论文：

1. 右键论文。
2. 点击文件夹图标或“添加到文件夹”。
3. 勾选一个或多个目标文件夹。
4. 点击“完成”后才应用更改。

多篇论文：

1. 长按任意论文进入多选，再选择其他论文。
2. 点击批量工具栏中的文件夹图标。
3. 弹窗中的勾选状态表示：全部已在该文件夹、部分在该文件夹或全部不在。
4. 勾选或取消目标文件夹，点击“完成”后统一应用。
5. 关闭或取消弹窗不会修改文件夹归属。

### 6. 快速多选

1. 长按任意论文，保持按住并直接向上或向下滑动，可连续选择经过的论文。
2. 进入多选后，点击复选框可继续选择或取消论文。
3. 也可以按住一个复选框拖动，连续选择或取消。
4. 完成批量操作后自动退出多选。
5. 点击论文列表空白处或按 `Esc` 也可退出多选。
6. `Command/Ctrl + A` 可全选当前列表。

### 7. 阅读状态

论文有未读、在读和已读三种状态。

1. 右键论文，或进入多选后点击状态图标。
2. 选择未读、在读或已读。
3. 论文库顶部筛选器可以只看某一种状态。
4. 打开和阅读论文时，状态与最后阅读时间会随使用情况更新。

### 8. 阅读计划

1. 右键论文，打开“加入阅读计划”。
2. 选择现有计划或新建计划。
3. 选择今天、明天或自定义日期。
4. 论文会出现在时间线页面对应计划和日期中。

### 9. 重命名论文

1. 右键论文。
2. 选择重命名。
3. 输入新标题并确认。此操作只修改论文库中的显示标题，不改原 PDF 文件内容。

### 10. 导出笔记

1. 右键单篇论文，或多选论文。
2. 点击下载图标或导出笔记。
3. 选择保存位置。导出内容包括已有高亮和批注。

### 11. 删除、恢复与清空回收站

1. 右键论文或多选论文，点击删除。
2. 论文先进入回收站，不会立刻永久丢失。
3. 打开左侧回收站，可恢复单篇论文或永久删除。
4. 点击回收站顶部的清空按钮，可永久删除回收站全部内容。

### 12. 搜索、筛选、排序与布局

- 顶部搜索框可匹配标题、作者、摘要、期刊或会议。
- 状态筛选器可选全部、未读、在读、已读或收藏。
- 排序可选添加时间、最近阅读或标题。
- 点击列表或网格图标切换布局。
- 列表行和卡片上的来源图标来自论文网页；无法取得时使用通用文档图标。
- 列表视图右键论文与右侧“更多”按钮打开相同菜单。
- 单击列表论文会打开右侧预览；拖动预览左侧分隔线可调整列表与预览的宽度比例。
- 解析完成后会同步生成中文标题和摘要；在右侧预览点击“原文 / 中文”切换。旧论文首次切换中文时会自动补译并缓存。

### 13. 管理文件夹

1. 点击侧栏底部的加号新建文件夹；也可右键“全部论文”或“收藏”新建。
2. 输入文件夹名称，选择颜色，需要时添加标签。
3. 右键已有文件夹可新建子文件夹、重命名、修改颜色与标签或删除。
4. 论文可以拖到文件夹；拖到未分类会移除其文件夹归属。

### 14. 重新解析

1. 在论文库右键论文。
2. 点击解析或重新解析。
3. 等待解析完成。适用于正文、摘要、作者、期刊会议等信息不完整的论文。

## 二、论文阅读

### 1. PDF 阅读与进度

1. 从论文库打开论文。
2. 使用滚轮阅读 PDF。
3. 阅读时长、最后阅读时间和位置会自动记录。
4. 顶部标签允许同时打开多篇论文并来回切换。

### 2. 目录、跳页与缩放

- 点击目录图标打开章节目录，再点击章节定位。
- 使用页码控件跳到指定页。
- 使用缩放按钮放大、缩小或适合页面。

### 3. 高亮

1. 在 PDF、译文或博客中选中文字。
2. 点击浮动工具栏中的高亮图标。
3. 在笔记列表查看高亮；点击记录可回到原位置。

### 4. 批注

1. 选中文字。
2. 点击批注图标。
3. 输入笔记并保存。
4. 在笔记列表中定位、查看或删除批注。

### 5. 划词翻译

1. 在 PDF、译文或博客中选中单词、术语或短句。
2. 点击翻译图标。
3. 结果显示在选区旁。单词和术语只返回精炼中文释义，短句直接返回译文。

### 6. 针对选文提问

1. 选中文字。
2. 点击提问图标。
3. 选中内容会作为上下文送入当前论文的 AI 助手。
4. 在右侧继续输入问题并发送。

### 7. 论文来源与 GitHub 项目

1. 打开论文阅读页。
2. 点击右上角的外部链接打开论文来源网页。
3. 如果解析到关联 GitHub 仓库，右上角会出现 GitHub 直达按钮；点击后在浏览器中打开项目。

## 三、AI 助手

### 1. 单篇论文问答

1. 打开论文右侧 AI 助手。
2. 输入问题并发送。
3. 回答以当前论文正文为主要依据。
4. 点击回答中的论文引用可跳回原文位置。

### 2. 快速模式

1. 点击输入框下方的模式按钮。
2. 选择快速。
3. 适合术语解释、直接定位、简短概括等问题。

### 3. 深度模式

1. 点击模式按钮并选择深度。
2. 输入需要多步检索或综合分析的问题。
3. 可展开查看检索和工具调用过程。

### 4. 联网检索

1. 打开 AI 输入框下方的联网开关。
2. 发送需要外部资料的问题。
3. 回答会区分论文引用和网页来源。

### 5. 会话历史与新会话

1. 点击 AI 面板右上角的历史图标。
2. 选择历史会话继续。
3. 点击加号开始新会话。
4. 论文切换后，会话和正在生成的任务按论文保存；返回原论文可继续查看。

### 6. 停止生成

1. 回答生成期间点击停止图标。
2. 已生成内容保留，后续可继续提问。

### 7. 知识库问答

1. 点击左侧知识库问答图标。
2. 输入需要跨论文比较或归纳的问题。
3. AI 会在论文库中检索相关内容。
4. 点击回答引用可打开对应论文和原文位置。
5. 右上角历史图标用于恢复会话，加号用于新建会话。

## 四、AI 翻译与学习

### 1. AI 全文翻译

1. 打开论文并切换到“AI 翻译”。
2. 点击开始翻译。
3. 翻译按段生成并保存；完成后可切换纯中文或中英对照。
4. 译文同样支持高亮、批注和划词操作。

### 2. AI 博客

1. 打开论文并切换到博客。
2. 点击生成博客。
3. AI 会生成易读正文和深度分析，并尽量保留论文图表。
4. 生成期间可以切换到其他论文；返回后继续查看进度和结果。
5. 已有博客可重新生成。

### 3. 费曼学习

1. 打开论文并进入费曼学习。
2. 让 AI 根据论文生成核心概念计划。
3. 检查并确认计划。
4. 每个概念使用独立会话：用户充当老师，把概念讲给 AI 学生。
5. 回答 AI 的追问，再进行概念测验。
6. 通过后进入下一个概念；完成后查看复盘和薄弱点。

### 4. 论文测验

1. 打开论文并切换到测验。
2. 点击新建测验。
3. AI 根据论文内容出题。
4. 完成作答并提交，查看评分、答案和解析。

## 五、论文搜索

### 1. 关键词搜索

1. 点击左侧搜索图标。
2. 选择关键词搜索。
3. 选择论文范围，输入关键词并按回车。
4. 点击结果可回到论文原文。

### 2. 语义搜索

1. 在搜索页面选择语义搜索。
2. 输入一个研究概念或自然语言问题。
3. 系统按含义查找相关段落，而不要求文字完全相同。
4. 点击结果打开对应论文位置。

## 六、阅读时间线与计划

### 1. 阅读时间线

1. 点击左侧日历图标。
2. 热力图显示每天的阅读活动，颜色深浅表示活跃程度。
3. 点击日期查看当天阅读记录和完成情况。

### 2. 建立阅读计划

1. 在时间线页面新建阅读计划并设置名称或目标。
2. 从论文右键菜单把论文加入计划。
3. 设置计划日期。
4. 在时间线中查看待读论文和完成进度。

## 七、浏览器扩展

### 1. 安装或更新

1. 解压 ZoomPaper Connector 扩展压缩包。
2. 打开 Chrome 或 Edge 的扩展管理页。
3. 开启开发者模式。
4. 点击“加载已解压的扩展程序”，选择扩展目录。
5. Connector `v0.2.8` 起使用固定扩展 ID；更新时解压新版并点击重新加载即可覆盖升级。更早版本需要先移除一次旧扩展。
6. 升级到 `v0.2.9` 时确认一次下载权限；它用于通过浏览器当前的验证会话导入 OpenReview PDF。

### 2. 从论文网页收集

1. 打开受支持的论文详情页，例如 ACL Anthology、arXiv、OpenReview、IEEE、ACM、Springer、ScienceDirect、PMLR、NeurIPS、CVF、USENIX 或通用 DOI 论文页。
2. 点击扩展按钮，或右键页面选择加入 ZoomPaper。
3. 扩展提取标题、作者、来源页、PDF 地址和网站图标，并打开 ZoomPaper 完成导入。
4. 导入后可在应用中解析正文；网页存在 GitHub 项目线索时，应用会提供项目直达入口。
5. OpenReview 若要求验证，先在当前页面完成验证，再使用扩展导入。

## 八、设置

### 1. 配置 AI 服务

1. 打开设置。
2. 选择 OpenAI、Anthropic、Gemini、DeepSeek 或兼容接口。
3. 填写 API 地址、密钥和模型；模型框提供常用建议，也可以直接输入服务商支持的任意模型名称。
4. 保存并测试连接。

AI 配置用于论文问答、知识库问答、全文翻译、划词翻译、博客、费曼学习、测验和帮助问答。

### 2. 配置 MinerU

1. 打开设置中的解析配置。
2. 填写 MinerU 所需信息。
3. 保存后回到论文库解析论文。

### 3. 数据与文件

- 论文、解析结果、翻译、博客、会话、高亮和批注保存在本机应用数据中。
- 删除论文先进入回收站；永久删除和清空回收站不可撤销。
- 修改论文库位置前，应确认目标位置可读写，并保留重要数据备份。

## 九、帮助

### 1. 浏览功能手册

1. 点击左侧帮助图标。
2. 先选择页面分类，再点击具体功能。
3. 右侧会显示该功能使用的图标、用途和逐步操作。

### 2. 问 AI

1. 在帮助页面底部输入“有没有某个功能”或“具体怎么操作”。
2. 发送问题。
3. AI 只根据本功能指南回答；若指南没有记载，应明确说明无法确认，不应编造按钮或操作。

## 十、常用快捷操作

- 将鼠标停在只有图标的按钮上，可查看用途提示。
- 右键论文可打开与“更多”按钮相同的操作菜单。
- 长按论文进入多选。
- 点击论文列表空白处或按 `Esc` 退出多选。
- `Command/Ctrl + A` 全选当前论文列表。
- `/` 或 `Command/Ctrl + F` 聚焦论文库搜索。
- 在输入框中按 `Enter` 发送；中文输入法正在组词时不会误发送。
