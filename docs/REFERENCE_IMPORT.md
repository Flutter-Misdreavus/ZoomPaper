# 从 Zotero 导入文献

ZoomPaper 支持导入 Zotero 导出的 **BibTeX（.bib）** 或 **RIS（.ris）**，并把匹配到的 PDF 复制进本地论文库。这是单向导入：不提供从 ZoomPaper 导出到 Zotero 的题录功能；整库归档请使用「设置 → 数据与存储 → 完整备份」。

## 使用步骤

1. 在 Zotero 中选中条目，右键 → 导出条目 → 选择 **BibTeX** 或 **RIS**，保存到本地。
2. 打开“设置 → 导入与解析 → Zotero 题录导入”，点击“导入题录”按钮。
3. 选择题录文件；如果导出文件不含附件路径，再选择一个 **附件根目录**（通常是 Zotero 的 `storage` 文件夹或导出文件夹）。
4. 点击「解析并预览」。此步骤只读取文件，不会写入论文库。
5. 检查重复项、PDF 匹配和导入方式，必要时逐条选择 PDF。
6. 可选点击「联网补全 DOI」：对缺失 DOI 的条目调用 Crossref 搜索，带进度和限流。
7. 确认后导入。可勾选「允许仅导入题录」保留没有 PDF 的条目；之后在论文详情中补挂 PDF。

## 去重与合并

- 优先按 DOI、PDF SHA-256 判断重复；其次按标题相似度、年份和作者。
- 高置信度重复项默认「合并」；标题相似但证据不足的标记为「疑似重复」，默认跳过，需要手动选择合并。
- 合并复用已有论文 ID、PDF、标注文件、会话和测验，**不会覆盖已有标注或文件夹归属**；只补充缺失的 DOI、年份、venue、作者、摘要和来源链接。
- 如果已有论文没有 PDF，而导入条目有 PDF，会补挂 PDF 并标记为未解析；已有 PDF 不会被替换。
- 目标文件夹会与已有文件夹取并集，不会移除原归属。

## 无 PDF 条目

- 默认跳过；勾选「允许仅导入题录」后可创建只有元数据的论文。
- 这类论文显示「缺少 PDF」，阅读器不会打开 PDF；在论文详情中点击「补挂 PDF」选择本地 PDF。
- 「替换 PDF」需要明确确认：已有标注会保留，但如果新旧 PDF 页码/布局不同，标注位置可能偏移。

## 附件匹配

- 支持 Zotero `file` / RIS `L1/L2` 中的绝对路径、相对路径、`storage:` 前缀。
- 选择附件根目录后，会按 PDF 文件名（basename）、题录标题/citation key 回退匹配；多个同名或可疑文件需要手动选择。
- 只接受有效的 `%PDF-` 文件和 100 MB 以内的文件；不跟随符号链接。

## 限制

- 不读取 Zotero 的收藏夹/分类，也不会把 Zotero 批注转换为 ZoomPaper 标注。
- 只保留 ZoomPaper 论文模型中的字段；BibTeX 的 volume/pages/publisher 等额外字段不会显示。
- 不支持完整 BibLaTeX 宏系统；损坏条目会跳过并在预览中列出。
- DOI 补全会联网访问 Crossref，可能受网络和限流影响；失败不会阻塞导入。

完整备份仍会包含论文目录下的标注、译文、博客和补挂的 PDF。
