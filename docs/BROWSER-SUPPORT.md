# 浏览器导入与会议图标

Connector 0.3.0 使用通用识别和浏览器下载，不要求事先适配某个会议。

## 识别与下载

1. 优先使用右键选中的链接、标准 `citation_pdf_url` 和论文 JSON-LD 中的全文地址。
2. 再使用已知的稳定全文规则和页面 PDF 下载入口。
3. 用浏览器下载全文，沿用浏览器的 Cookie、登录与网络环境。
4. 失败时最多尝试三个由元数据或稳定规则提供的地址。普通页面链接由用户选择，避免误选相关论文。
5. 未找到全文或重试失败时打开恢复页：选择其他候选、粘贴 HTTPS 全文地址、打开原网页或查看诊断记录。

候选链接去重并排除补充材料、海报、幻灯片和 checklist。显式右键某个链接时尊重用户选择。支持没有 `.pdf` 后缀的下载接口。

下载状态存放在浏览器会话存储中；扩展后台休眠后由下载事件继续处理。浏览器关闭或扩展重新加载后会话记录可能失效，需要重新导入。文件上限 100 MB，每次下载超时两分钟。扩展检查浏览器返回的文件类型，App 再检查 PDF 文件头。

## 常见来源

| 来源 | 识别方式 |
| --- | --- |
| arXiv、OpenReview、ACL Anthology | 稳定全文地址和页面元数据 |
| ICLR、NeurIPS Proceedings、CVF | 稳定全文规则和页面元数据 |
| ACM DL、IEEE Xplore、Springer、USENIX、PMLR/JMLR | 标准元数据和全文链接 |
| Researchr 和其他会议页面 | 页面中的公开全文或 arXiv / OpenReview 入口 |
| 新会议、机构仓库、个人论文页 | 标准元数据、PDF 链接或手动指定全文 |

这些是识别策略，不能保证每个网站、每篇论文都成功下载。机构订阅、验证码、付费墙、过期下载地址、脚本生成且尚未展示的链接，需要在浏览器完成相应操作。扩展不绕过访问控制。

搜索结果页包含多篇论文时，请在目标全文链接上右键，或进入该论文详情页。

## 会议与图标

会议身份来自论文的会议元数据、首页或明确的会议来源地址。PMLR、OpenReview 等托管多个会议的平台不会整体归类为单一会议。

App 会从 Connector 提供的 DOI、DOI 来源链接或 PDF 首页提取 DOI，自动查询 Crossref；Crossref 未收录时尝试 DataCite。只有返回标题与解析标题匹配时才补全缺失的会议／期刊、年份和作者，也可将 arXiv / OpenReview 平台标签补全为正式出版信息。已有具体会议信息和自定义标题保留。未收录在图标映射表里的出版物名称同样可以显示。

无需账号、API Key 或模型调用。查询只向元数据服务发送 DOI，不发送 PDF 或正文。缓存保存在本机；查询成功缓存 30 天、未收录缓存 1 天，已确认的单篇论文信息持久保存。查询限时、串行并处理限流，失败不影响解析或阅读。旧论文在打开概览或阅读时自动尝试补全；没有 DOI 的论文继续使用原有识别。

已知独立会议使用内置品牌图标；ACM、IEEE、USENIX 系会议优先使用导入时捕获的页面图标，再使用组织品牌。新会议使用页面声明的 favicon 或来源网站图标。所有图标均加载失败时显示文件图标。

品牌映射在 `src/components/library/VenueBadge.tsx`，内置图片位于 `public/venue-icons/`。图标由 App 加载时选择，已有论文无需重新导入。该目录不表示 CCF 等级。

## 隐私与恢复

扩展只在用户点击导入时读取当前页。会话记录保存标题、来源、候选地址、下载状态与失败原因，不保存 API Key 或论文正文。PDF 暂存到 `ZoomPaper Imports`，成功交给 App 导入后由 App 删除。浏览器已下载但尚未交给 App 的文件可能保留，可从下载记录手动删除。

Connector v0.4.0 通过固定扩展 ID 的本机回执接口确认保存成功，成功后显示“已加入论文库”。App 未确认时可重新发送同一请求；请求 ID 和新导入文件的内容指纹避免重复。回执不表示解析已完成，解析进度在 App 阅读小伙伴中查看。接口仅接受本扩展来源的单个请求状态查询，不提供正文、密钥或修改操作。
